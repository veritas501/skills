# Common

General-purpose skills that aren't tied to any one domain or workflow — reach for them across any project.

Unlike a phased pipeline, these are independent tools: each solves a self-contained problem and carries no dependency on the others. Add a skill here when it's broadly reusable and doesn't belong to a more specific domain.

- **[handoff](./handoff/SKILL.md)** — Generate a cross-session context summary written *for the next agent*, not the user: verbatim user requests, current state, pending tasks, rules, and the gotchas you hit, so a fresh session continues without re-discovering everything. Use when context grows long, quality degrades, or you want a clean restart.
- **[readme-writer](./readme-writer/SKILL.md)** — Author or review a `README.md` from the first-time reader's perspective, with rules that keep it honest: every command tied to real project evidence (no guessed run commands), secrets always redacted, scope held to an entry point rather than an encyclopedia.
- **[skill-writer](./skill-writer/SKILL.md)** — Author, edit, or review an agent skill (`SKILL.md`), with rules that keep it complementary to the agent rather than redundant: write only the non-obvious constraints and decisions the agent doesn't already know, cut content it can derive itself, and keep frontmatter triggers precise.
