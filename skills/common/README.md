# Common

General-purpose skills that aren't tied to any one domain or workflow — reach for them across any project.

Unlike a phased pipeline, these are independent tools: each solves a self-contained problem and carries no dependency on the others. Add a skill here when it's broadly reusable and doesn't belong to a more specific domain.

- **[agent-deslop](./agent-deslop/SKILL.md)** — Strip AI slop from a specified scope (by default, the code changed in the current session): process artifacts in comments — plan/phase tags, temporal or conversational phrasing, narration that merely restates the code — and structural bloat such as needless nesting, dead code, redundant defensive checks, and pass-through wrappers. Design intent, invariants, and contracts are preserved and behavior never changes; a cleanup that cannot be shown to be behavior-neutral is reported rather than applied.
- **[git-bump-version](./git-bump-version/SKILL.md)** — Commit pending work separately, then prepare a clean SemVer release transaction whose release commit contains only canonical version metadata, with categorized release notes and a matching annotated Git tag.
- **[engineering-taste](./engineering-taste/SKILL.md)** — Judge code structure by healthy ownership and dependency direction: spot unclear ownership, fake modularity, and speculative abstractions, and steer toward local precedents before inventing new ones.
- **[handoff](./handoff/SKILL.md)** — Generate a cross-session context summary written *for the next agent*, not the user: verbatim user requests, current state, pending tasks, rules, and the gotchas you hit, so a fresh session continues without re-discovering everything. Use when context grows long, quality degrades, or you want a clean restart.
- **[readme-writer](./readme-writer/SKILL.md)** — Author or review a `README.md` from the first-time reader's perspective. Every claim is tied to evidence in the repository (commands, features, example identifiers, supported versions), secrets are always redacted, scope is held to an entry point rather than an encyclopedia, and license and other owner decisions are left to the user with a reminder; reference files cover wording, complete example READMEs, and special cases such as images and translations.
- **[skill-writer](./skill-writer/SKILL.md)** — Author, edit, or review an agent skill (`SKILL.md`), with rules that keep it complementary to the agent rather than redundant: write only the non-obvious constraints and decisions the agent doesn't already know, cut content it can derive itself, and keep frontmatter triggers precise.
