# Language style routing

Project formatter, linter, API contract, and healthy local style take precedence over these defaults.

| Language | File | Source status |
|---|---|---|
| Python | `python.md` | Official Google guide + explicit project engineering import decisions |
| Go | `go.md` | Official Google Go guide/decisions/best practices |
| JavaScript | `javascript.md` | Official but frozen; Google recommends TypeScript for new work |
| Java | `java.md` | Official Google guide |
| C++ | `cpp.md` | Official Google guide |
| C | `c.md` | No official Google C guide; pragmatic C-applicable subset |
| Rust | `rust.md` | No official Google Rust guide; rustfmt/clippy idioms |

These files adapt syntax and tooling. Structural ownership and function/object decisions live in `../design.md`.

Provenance and licensing: `sources.md`.
